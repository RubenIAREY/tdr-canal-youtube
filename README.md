# Canal de YouTube de TDR · evolución, proyección y coste

Web estática que explica cómo ha crecido el canal de YouTube de [TodoEnRecambio](https://todoenrecambio.com) desde que los vídeos se hacen con inteligencia artificial (4 de agosto de 2026), cuánto cuesta, qué está automatizado y una proyección con tres escenarios hasta el 31/12/2027.

- `index.html`, `estilos.css`, `app.js`: la web (Chart.js por CDN).
- `datos.json`: los datos, generados desde YouTube Analytics y Google Analytics con `VIDEOS/analisis-canal/_web_datos.py`.
- El simulador de `app.js` usa el mismo modelo que `_proyeccion.py`.

Datos a 1 de octubre de 2026.
